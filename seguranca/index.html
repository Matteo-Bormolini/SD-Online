Regras de acesso

Quem pode ver cada parte do site. Fonte única: seguranca/acesso.js (tela) e seguranca/permissoes.json (servidor).

Recursos e perfis com acesso

Regras gerais

  1. Negar por padrão: recurso sem regra fica bloqueado.
  2. Prestador não acessa áreas exclusivas de cliente (CPF ou CNPJ).
  3. Cliente CNPJ não acessa dados de Cliente CPF, e vice-versa.
  4. CPF, telefone e endereço completo de Cliente CPF nunca são públicos.
  5. Nada é exibido sem a autorização marcada no cadastro; a pessoa pode retirá-la quando quiser (LGPD).
  6. O administrador vê dados sigilosos para suporte, mas nunca a senha (só o hash fica no servidor).

A tela esconde, o servidor bloqueia

Esconder um botão não protege o dado. Na plataforma real, cada página e cada consulta ao banco conferem no servidor o perfil de quem está logado e se o dado é dele, usando estas mesmas regras. Ao mudar uma regra, altere acesso.js e permissoes.json.
