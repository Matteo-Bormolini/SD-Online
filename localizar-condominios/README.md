# Seus Serviços (área do prestador)

Futura página do prestador com o mapa dos clientes que estão orçando ou fazendo serviço com ele.
O nome da pasta é antigo; no menu ela aparece como **Seus Serviços**.

## Quem vê
- Só o **prestador** (e o adm).

## Regras já decididas
- O mapa mostra só a **região aproximada** do cliente, nunca o endereço exato.
- O prestador nunca vê clientes de outros prestadores.
