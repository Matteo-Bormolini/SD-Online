# Chaves de API

**Nunca coloque chaves reais aqui.** Este repositório guarda apenas o modelo `.env.example`.

- As chaves reais ficam no arquivo `.env` (bloqueado pelo `.gitignore`) ou no painel do servidor de hospedagem.
- Se uma chave for enviada ao GitHub por engano, cancele-a no serviço e gere outra.
