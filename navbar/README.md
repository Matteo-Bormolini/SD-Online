# Navbar

Barra de navegação do topo (vinho #800000, texto branco).

- `navbar.js`: monta a barra, o botão de tema (claro/escuro) e o menu compacto (3 riscos abaixo de 1260px).
- `navbar.css`: aparência da barra.
- Os itens do menu ficam em `configuracoes/config.js` (não aqui).
- Itens com cadeado só liberam depois do login.
