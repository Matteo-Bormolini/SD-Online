# Menu do topo (NavBar)

A barra vinho no alto de todas as páginas.

## Quem vê
- Todos. Cada tipo de conta vê só os itens que pode usar.

## O que tem
- Início · Serviços 🔒 (clientes) · Seus Serviços 🔒 (prestador) · Sobre nós · Políticas · Suporte.
- 🔒 = leva ao login se a pessoa ainda não entrou.
- Botão de tema claro/escuro (a escolha fica salva).
- Entrar / Criar conta (visitante) ou Meu perfil / Sair (com conta).
- Abaixo de 1260 px vira o botão de 3 riscos.

## Arquivos
| Arquivo | Para que serve |
|---|---|
| `navbar.js` | Monta a barra, o tema e o menu compacto. |
| `navbar.css` | Visual da barra. |

## Como mudar
- Itens e links → `configuracoes/config.js`. Quem vê cada item → `seguranca/acesso.js`.
