# Imagens das divulgações (Home do prestador) · v0.8.2

Imagens de **eventos** e **grupos** cadastrados pelo adm na coleção `divulgacoes`.

- Envie a imagem para esta pasta (GitHub → Add file → Upload files).
- No console, campo `imagem` = **só o nome do arquivo** (ex.: `feira-marcenaria-2026.webp`).
- Nome: letras minúsculas, números e hífen; termina em `.webp`, `.jpg`, `.jpeg` ou `.png`. Sem espaço e sem acento.
- Tamanho sugerido: **1280 × 720 px** (evento) · **256 × 256 px** (logo de grupo). Até ~200 KB.
- Use só imagens que o organizador autorizou. Sem fotos de pessoas sem autorização.
- Links de imagens de outros sites são bloqueados de propósito (segurança e privacidade: evitam rastreamento).

## Imagens de exemplo (v0.8.3)
`exemplo-networking.webp`, `exemplo-nr10.webp`, `exemplo-marcenaria.webp`, `exemplo-grupo-marcenaria.webp`: usadas pelos **exemplos ilustrativos** (aba Divulgações do adm). Imagens abstratas, sem pessoas nem marcas. **Apagar antes do lançamento.**

Também dá para enviar a imagem direto pela aba Divulgações (botão "Escolher imagem"): ela é reduzida e salva no banco, sem precisar desta pasta.
