# Fotos e marca

A logo da S.D e as fotos que aparecem quando alguém ainda não colocou a sua.

## Pastas
| Pasta | O que tem |
|---|---|
| `marca/` | Logo (engrenagem com capacete) em vinho, branca e sobre fundo vinho. **Provisória.** |
| `marca/lojas/` | Lugar para os selos oficiais das lojas de apps ([LEIA-ME](marca/lojas/LEIA-ME.md)). |
| `padrao/` | Fotos padrão de Cliente CPF, Cliente CNPJ e Prestador. **Provisórias** ([LEIA-ME](padrao/LEIA-ME.md)). |

## Como mudar
- Trocar a logo: salve o arquivo novo **com o mesmo nome** e atualize `ICONES.logo` em `configuracoes/config.js`.
- Trocar uma foto padrão: mesmo nome, quadrada, mínimo 200 × 200 px.

## Regras
- Fotos dos usuários **nunca** vão para o GitHub (`.gitignore` bloqueia `fotos/usuarios/`).
- Aceitos: JPG, PNG e WEBP até 5 MB.
- No servidor, toda foto perde os dados escondidos (EXIF), que podem mostrar onde foi tirada.
