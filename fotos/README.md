# Armazenamento de fotos

- `marca/`: logo e imagens do próprio site.
- Fotos enviadas pelos usuários (perfil e galeria) **não** ficam no GitHub: vão para o armazenamento do servidor (a definir). A pasta `fotos/usuarios/` está bloqueada no `.gitignore`.
- Formatos aceitos: JPG, PNG, WEBP até 5 MB; galeria com no máximo 12 fotos.
