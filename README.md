# Documentação

Os documentos que guiam o projeto. Comece pelo backlog.

| Arquivo | Para que serve |
|---|---|
| [`backlog.md`](backlog.md) | Macro-objetivo, caminho do pedido, épicos, histórias, MoSCoW, Sprints e decisões em aberto. **É o plano do produto.** |
| [`guia-tecnico.md`](guia-tecnico.md) | Como o código é organizado e como criar páginas. |
| [`padrao-global.md`](padrao-global.md) | Regras visuais que valem para todas as páginas. |
| [`prompt-mestre-padrao-visual.md`](prompt-mestre-padrao-visual.md) | Padrão visual completo (texto usado com a IA). |
| [`decisoes.md`](decisoes.md) | Detalhes de marca, visual e do perfil do administrador. |

> Se uma decisão mudar o plano, anote no `backlog.md`. Se for uma regra de visual, anote no `decisoes.md`.
