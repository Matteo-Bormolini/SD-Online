# Botões liga/desliga (consulta)

Página que mostra **todos** os botões liga/desliga do site em cartões:
o que cada um faz, se começa ligado ou desligado, quem tem e onde fica.

## Quem vê
- Só o **administrador**.

## Arquivos
| Arquivo | Para que serve |
|---|---|
| `index.html` | A página. |
| `interruptores.js` | Monta os cartões a partir da lista. |
| `interruptores.css` | Visual dos cartões. |

## Como mudar
- A lista **não** fica aqui. Ela fica em `configuracoes/interruptores.js`.
- Cadastrou um botão novo lá? Ele aparece aqui sozinho.
