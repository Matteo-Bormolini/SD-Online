# Início (Home) e Sobre nós

A primeira página do site e a página "Sobre nós".

## Quem vê
- **Visitante:** apresentação da S.D e a lista de serviços (só os nomes).
- **Cliente (CPF ou CNPJ):** atalhos para encontrar prestadores e o caminho do pedido.
- **Prestador:** só atalhos. **Nunca** vê dados de outros prestadores.

## Arquivos
| Arquivo | Para que serve |

| `index.html` / `home.css` / `home.js` | Página inicial. |
| `sobre.html` | Sobre nós (provisória: "em desenvolvimento"). |
